# Prompt para la primera sesión en Claude Code

Copia y pega esto la primera vez que abras Claude Code dentro de esta carpeta:

---

Lee `CLAUDE.md`, el skill `aurasleep-marca`, `docs/contenido.md`, `docs/datos.json`, `docs/enlaces.md` y `modelo-3d/LEEME.md`. Después mira las imágenes de `public/img/`.

Quiero construir el sitio web de AuraSleep: una sola página de producto (landing) en español, con HTML, CSS y JavaScript sin framework, que se vea premium y tranquila y que cuente la historia de la noche al amanecer conforme se baja.

Secciones, en este orden:
1. Hero: producto, eslogan y dos botones.
2. El problema: tres efectos de la alarma ruidosa.
3. Cómo funciona: línea de tiempo interactiva de −15 a 0 minutos (al moverla cambia la imagen de noche a amanecer y aparecen las ráfagas de aroma).
4. El producto: el modelo 3D incrustado, botones para las vistas superior, lateral e interna, selector de los 3 colores y ficha técnica.
5. Ventaja competitiva: la tabla comparativa.
6. Para quién es: tres tarjetas.
7. Precio y cartuchos, con la nota de que las cifras son hipotéticas.
8. Preguntas frecuentes en acordeón.
9. Cierre: lista de espera demostrativa (sin enviar datos a ningún servidor), enlaces a Canva, PDF descargable y créditos del equipo con marcadores.

Antes de escribir código, proponme la estructura de archivos y un boceto breve de cada sección. Cuando lo apruebe, constrúyelo, ábrelo en el navegador, revísalo en tamaño de escritorio y de celular, y corrige lo que se vea mal.
